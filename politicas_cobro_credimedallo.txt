4. REGLAS DEL FLUJO DE COBRO
   4.1 Prioridad: se prioriza el cobro a clientes con mora superior a 3 meses
       (más de 90 días) o con créditos sin ningún pago registrado.
   4.2 Consulta de saldo: si el cliente pregunta su saldo, se le informa el
       valor exacto en pesos colombianos según la base de cartera.
   4.3 Comprobantes de pago: si el cliente envía un comprobante, se le
       agradece y se escala obligatoriamente a Melisa (Coordinadora de
       Cartera) para validación bancaria antes de registrar el abono.
   4.4 Escalamiento obligatorio a Melisa (Coordinadora de Cartera): cuando el
       cliente pida descuentos, condonación de intereses o acuerdos de pago
       especiales, o presente reclamos de garantía.
   4.5 Falta de respuesta: si pasan más de 3 días sin respuesta del cliente
       por WhatsApp, se genera una alerta interna para que un asesor humano
       programe una llamada telefónica.
   4.6 Devoluciones: no se aceptan devoluciones de electrodomésticos usados
       ni se reembolsa el dinero pagado. Toda solicitud de devolución, retiro
       del producto o dación en pago se escala obligatoriamente a Melisa
       (Coordinadora de Cartera).

5. PROTECCIÓN DE DATOS (Ley 1581 de 2012)
   Los clientes se identifican únicamente por código (C-001 a C-020). No se
   manejan nombres, cédulas, teléfonos ni direcciones en esta base.
